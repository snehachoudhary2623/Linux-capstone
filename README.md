
# Linux System Administration & Automation Toolkit

## Project Description
This project is a Linux-based administration toolkit
developed using Bash scripting.

It combines system monitoring, backup, log analysis
and a menu-driven dashboard.

## Modules
1. monitor.sh - Monitors CPU, memory and disk usage.
2. backup.sh - Performs backup and restoration.
3. log_analyzer.sh - Analyses system log files.
4. dashboard.sh - Provides a menu-driven interface.

## Requirements
- Linux / Ubuntu
- Bash Shell
- Terminal
- Nano Editor
- tar, grep and awk utilities

## Execution

Give permission:
chmod +x *.sh

Run the dashboard:
./dashboard.sh
